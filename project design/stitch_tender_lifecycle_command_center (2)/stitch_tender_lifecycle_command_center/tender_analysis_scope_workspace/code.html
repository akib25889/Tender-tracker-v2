2.0 Technical & Infrastructure Specifications

Architecture constraints and security compliances (RFP Sec 5)

Deep Extraction
cloud_circle Data Sovereignty & Hosting

Strict mandate: All customer transactional and master data must physically reside in a Tier-3 or Tier-4 Sovereign Datacenter inside Bangladesh territory. Public multitenant cloud prohibited without dedicated private enclave encryption.

Complies: BD National Data Center (BCC) & Tier-3 Equinix JV Partner
database Database Management Engine

High-availability active-active cluster support required. Supported engines: PostgreSQL Enterprise 15+ or Oracle Real Application Clusters (RAC) 19c+. Must guarantee recovery point objective (RPO) < 5 minutes.

Proposed: Enterprise PostgreSQL with Patroni & Barman cluster
security Security & Certifications

Mandatory ISO-27001:2022 and ISO-22301 certifications required at time of bid. Architecture must align with FedRAMP High baseline controls, TLS 1.3 in-transit encryption, and AES-256 at-rest.

Our Certs: ISO-27001 (Valid until 2028), ISO-20000-1 (Active)
hub Interoperability & APIs

RESTful OpenAPIs with OAuth2/mTLS. Out-of-the-box connectors required for Bangladesh Electronic Funds Transfer Network (BEFTN), Real-Time Gross Settlement (RTGS), and National NID Verifier gateway.

Integration status: Pre-built BEFTN microservice adapter ready
