# TenderTracker Project Knowledge Graph

> Generated by Graphify engine for instant, low-token codebase retrieval.

## 1. Core Lifecycle Pipeline

- **Stage 1 - Discovered**: Scanner or manual intake with confidence scoring
- **Stage 2 - Screening**: Entity jurisdiction check, restrictions, threshold screening
- **Stage 3 - Analysis & Go/No-Go**: Clause extraction, AI suitability, weighted decision matrix
- **Stage 4 - Preparation**: Task kanban, document vault population, requirement checklist
- **Stage 5 - Review & Approval**: 4-tier sign-off (Technical, Financial, Legal, Executive)
- **Stage 6 - Submission & Post-Award**: Portal upload proof, SHA-256 timestamps, win/loss ledger

## 3. Database Entities & Relationships

- **`users`**: Accounts, hashed passwords (Argon2id), roles
- **`tenders`**: Core tender records, status, stage, valuation, deadlines
- **`tender_decisions`**: Go/No-Go score matrix and executive rationale
- **`tender_tasks`**: Individual tasks, assignments, kanban column, due dates
- **`documents`**: Document metadata, categories, relative storage paths
- **`document_versions`**: Immutable file revisions with SHA-256 checksums
- **`tender_requirements`**: Compliance matrix clauses and evidence links
- **`tender_reviews`**: Multi-tier approval sign-offs and comment audit trail
- **`audit_logs`**: System-wide immutable security and activity log
- **`reusable_documents`**: Corporate master credentials, validity expiration, access tiers
- **`tender_comments`**: Real-time proposal remarks, debrief notes, and cross-team chat

## 4. Local File Storage Vault

- `storage/tenders/{TDR-ID}`: Local SSD root per tender
- `01_original_tender_documents`: Official RFP notices and specs
- `02_company_statutory_documents`: Trade license, tax clearance, solvency
- `03_technical_proposal`: Scope, methodology, CVs, credentials
- `04_financial_proposal`: BOQ, pricing tables, bank guarantees
- `05_final_submission_package`: Compiled and sealed proposal bundles
- `06_submission_receipts`: e-GP / UNGM upload receipts & confirmations
